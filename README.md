# ADB 文件浏览器

浏览 Android 设备文件（通过 adb）：左边目录树懒加载，右边文件列表，支持拉取/推送/删除/重命名/新建文件夹，带传输进度队列、文件名过滤、多设备切换。

## 运行

需要 `adb` 在 PATH 中且设备已授权。

```
uv run adb文件浏览器.pyw
```

或直接双击 `adb文件浏览器.pyw`。

## 操作

| 操作 | 方式 |
|---|---|
| 进入目录 | 双击列表项 / 展开树节点 |
| 拉取 / 推送 / 删除 / 重命名 | 右键菜单（Delete 键 = 删除，F5 = 刷新） |
| 过滤 | 右上输入框，子串匹配，仅作用于当前目录已加载内容 |
| 切换设备 | 左上设备下拉框（⟳ 刷新在线设备） |

## 结构

- `adb文件浏览器.pyw` — 入口（高 DPI 适配）
- `ui.py` — 全部 tkinter 界面
- `adb.py` — 命令层：常驻 shell、设备列表、pull/push 传输
- `fs.py` — 纯函数：ls 解析、路径处理

自检：`uv run python fs.py && uv run python adb.py`，输出 `ok` 即通过。
