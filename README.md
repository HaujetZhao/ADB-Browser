# ADB 文件浏览器

浏览 Android 设备文件（通过 adb）：左边目录树懒加载，右边文件列表（含大小），支持拉取/推送/删除/重命名/新建文件夹，带传输进度队列、文件名过滤（通配符）、多设备切换、拖拽收发文件。

## 运行

需要 `adb` 在 PATH 中且设备已授权。

```
uv run main.pyw
```

## 操作

| 操作 | 方式 |
|---|---|
| 进入目录 | 双击 / 树展开 / 列表上回车 |
| 上级 | ↑ 按钮 / Backspace |
| 刷新 | F5 |
| 重命名 | F2 / 右键 |
| 删除 | Delete / 右键（目录递归删除，有确认） |
| 全选 | Ctrl+A |
| 过滤 | 直接打字（自动聚焦过滤框）/ Esc 清空；含 `* ? [` 时按通配符，否则子串，均忽略大小写 |
| 拉取 / 推送 | 右键菜单，或**拖出**条目到资源管理器 / **拖入**文件到列表（拖出走临时目录，大文件拖出时会等待拉取） |
| 切换设备 | 左上设备下拉框（⟳ 刷新在线设备） |

传输完成后状态列显示 adb 摘要：文件数、平均速度、总大小、耗时。

## 结构

- `main.pyw` — 入口（高 DPI 适配、拖拽后端）
- `ui.py` — 全部 tkinter 界面
- `adb.py` — 命令层：常驻 shell、设备列表、pull/push 传输
- `fs.py` — 纯函数：ls 解析、路径/大小处理、过滤匹配

自检：`uv run python fs.py && uv run python adb.py`，输出 `ok` 即通过。
